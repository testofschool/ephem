# Security policy

EPHEM is experimental. Do not treat a successful fixture run as approval for a
production workload. Read [the threat model](docs/THREAT_MODEL.md) first.

Report a vulnerability privately through this repository's **Security → Report
a vulnerability** page. Include the affected commit, Linux/kernel architecture,
minimal synthetic reproducer, expected boundary and observed result. Never put
credentials, real customer data or weaponized payloads in a public issue.

There is no promised response SLA, paid bug bounty, certification, or externally
audited supported release. The current experimental branch is the review target.

Report ordinary compatibility bugs through GitHub Issues. Security fixes and
host/interpreter patches remain necessary; request disposal does not replace them.
